---

先读取 `java-review:skills/review/references/checklist.md`。

1. 确定本轮范围，并用只读 Git 工具了解已有修改。
2. 从实际入口追踪服务、工具或持久化调用，区分当前启用路径和静态可达路径。
3. 与修改前行为比较，区分新增回归和原有缺陷。
4. 只报告有具体触发条件和业务影响的问题，提供文件路径、行号及最小修正建议。
5. 验证必须依据真实命令输出。文件修改和测试继续使用宿主现有审核与审批；本技能不授予额外权限。

没有足够证据时明确说明，不声称已经运行测试或修改文件。
