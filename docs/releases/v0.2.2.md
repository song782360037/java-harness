## 新增流水线

从侧栏打开「流水线」，用自然语言描述一项反复发生的协作，生成流程图，预览确认后保存。可为不同岗位设置职责、模型和审批模式。每次手动发起事项后，Agent 按流程处理，并根据各岗位的结论选择下一步；需要人工决定时会暂停等待。

## 预置 PR 流水线

全新安装或从旧版升级后，可在「流水线」中选择「PR 流水线」并手动发起事项。流程依次经过门禁检查、代码审查和风险评估；不符合评审条件或需要修改时打回，高风险事项交由人工验收。默认不绑定工作区，如需检查代码，可先绑定对应工作区，再在事项中填写 PR 分支、链接或改动说明。

**「可以合并」只记录评审结论，不会执行合并。** 本版本也不会监听 GitHub PR 事件来自动发起事项。

## 人工待办入口

在「流水线 → 待你处理」集中查看各条流水线的待办，包括人工验收、岗位未能给出可用于流转的结论或运行失败，以及运行中等待审批或回答的事项。打开事项可选择下一步，或在可重试时重跑当前岗位；等待审批或回答时，点击「去处理」进入事项会话。
