## 流水线接入任务中心、桌面通知与侧栏角标

- 顶栏**任务中心**将流水线事项以独立来源 `FLOW` 汇总，不再拆散为普通会话任务。
- 事项停在人工验收节点、岗位失败暂停（`WAITING_DECISION`），或岗位运行中等待审批与回答时，桌面端会自动弹出系统通知，点击条目或通知即可直接打开对应事项。
- 左侧栏「流水线」入口实时展示待处理事项数量角标。

## 定时自动化支持触发流水线

- 在侧栏 **自动化** 中新建或编辑自动化时，可将执行目标切换为「触发流水线」，按每天 / 工作日 / 每周 / 每小时 / Cron 或手动方式定时发起新事项。
- 上一次触发的流水线事项仍在流转或等待人工处理时会自动防重入并记录跳过原因；运行历史中的记录支持一键跳转到对应事项。

## 流水线与群聊全面支持 ACP 外部智能体

- **流水线岗位绑定 ACP**：在流程图中点选任意 `AGENT` 岗位节点，即可将执行方式切换为已配置的本地 ACP 外部智能体（如 Codex、Claude Code 或自定义适配器）；内置模型与 ACP 岗位之间流转时会自动携带前序岗位产出，避免跨执行器上下文丢失。
- **群聊成员绑定 ACP**：在群聊设置的成员编辑中可将成员切换为 ACP 外部智能体；运行中到达的权限审批与结构化追问会实时刷新到群聊时间线，且按历史运行记录展示，后续修改成员执行方式不会隐藏既有交互记录。

详细说明见 [固定流水线](https://github.com/song782360037/java-harness/blob/master/docs/flows.md) 与 [外部智能体（ACP）](https://github.com/song782360037/java-harness/blob/master/docs/external-agents.md)。
