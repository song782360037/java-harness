## 跨平台桌面安装包（Windows / macOS / Linux）

- **全平台原生构建**：现同时发布 Windows x64（`.exe`）、macOS Apple Silicon（`mac-arm64.dmg`）、macOS Intel（`mac-x64.dmg`）以及 Linux x64（`.AppImage` 与 `.deb`）桌面安装包，均内置按平台裁剪的精简 JDK 21 运行时，开箱即用。
- **跨平台桌面体验适配**：macOS 保留原生应用/编辑/窗口菜单与 Dock 唤回窗口能力，菜单栏托盘图标按 macOS 尺寸适配；Linux 在精简桌面环境缺少托盘扩展时优雅降级，不阻塞启动或关闭。
- **自动更新兼容与扩展**：现有 Windows x64 自动更新链路（`latest.yml`）保持 100% 兼容；新增 Linux x64 AppImage 应用内自动更新（`latest-linux.yml`）；macOS 暂未签名时保持停用应用内自动更新并提示下载 DMG 覆盖安装。

## 核心代码结构重构

- 将前端主入口 `App.vue` 拆分为侧栏 `AppSidebar.vue` 与对话卡片 `ChatRunCard.vue`。
- 将后端 `PluginService`、`JdbcSessionStore` 与 `DefaultAgentEngine` 按职责拆分为独立包内协作类，在保持全部公共 API、SPI、数据库与锁语义不变的前提下显著降低单文件复杂度。
