## 桌面 Bot 团队工作台、沙箱互动小程序与局域网手机伴侣

- **独立 Bot 团队工作台（Flyway V34/V35）**：支持组建多角色常驻 Bot 团队，提供聊天/后台任务分离调度、跨 Bot `@` 静默委派、双区文件（专属资料库 + 绑定项目工作区）、做法（SOP）沉淀与全局技能一键导入、例行定时任务以及外部 ACP 智能体接入。
- **3D 翻面工牌、实时工位与沙箱互动小程序**：内置 30 款原创分层矢量角色图库（Deskfolk 30）、段位经验成长、3D 翻面工牌与明暗自适应工位、顶部灵动岛；Bot 可在后台生成单文件 HTML 互动小程序，运行于沙箱 `iframe` 并通过 `window.harnessBot` 桥接数据，最小化后支持 5 分钟热保活停靠栏。
- **独立按需局域网手机伴侣**：默认关闭、按需启停的独立端口（默认 `4317`）服务，支持同一 Wi-Fi 下扫码与 4 位配对码 + HttpOnly Cookie 安全配对，手机端可查看 Bot 团队、收发消息、打开小程序并按需开启 Bot 后台任务命令审批。
- **模块整合**：移除与 Bot 功能重叠的旧群聊前后端模块，保留既有数据库迁移与历史会话过滤兼容性。

## 9 套精选明暗主题与工作台视觉升级

- **多套明暗主题**：新增 **纯白极简**、**暖纸米白**、**晴空海蓝**、**落樱浅粉**、**午夜星蓝**、**暖棕咖啡** 与 **星云暗紫**，连同 **翡翠浅色 / 翡翠深色** 共 9 套原生精调明暗主题，并移除跟随系统选项，切换即刻生效并自动保存。
- **界面质感打磨**：系统优化主工作台、设置页、命令面板、文件浏览器与桌面端启动页的明暗对比、层次和交互细节。

## 全本机多 Agent 用量统计升级

- **新增 Antigravity 用量统计**：在既有 Java Harness、Claude Code、Codex、WorkBuddy 与 Qoder 基础上新增本机 Antigravity 会话记录（transcript）统计与配色标识。
- **并行解析、持久化缓存与启动预热**：改为流式按需字段提取与多线程并行解析，支持磁盘增量缓存（`harness.usage.cache-file`，重启仅重解析变更文件）及应用就绪后后台低优先级预热（`harness.usage.warm-up`），显著降低首次打开统计页的等待耗时。

## 模型容错增强与桌面更新体验修复

- **上游与解析失败区分及自动重试**：细化模型请求上游错误与响应解析失败分类，补充脱敏诊断日志，并对瞬态网络与限流错误自动退避重试。
- **桌面端更新说明安全渲染**：安全渲染桌面客户端发布说明并兼容多版本格式。
