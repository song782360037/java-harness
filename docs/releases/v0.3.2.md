## 工作区文件树与代码预览右侧栏

- **内置项目浏览器**：绑定工作区后，可在顶栏点击文件夹图标或通过命令面板展开右侧工作区文件栏（支持拖拽调整宽度并自动记住，窄屏自动切为抽屉视图）。
- **多根目录树与快速定位**：支持单根目录与多根目录（`@1` / `@2`）展开折叠、按文件名实时模糊定位，并严格复用工作区路径安全与敏感文件过滤规则（`.git`、`node_modules`、`.env*`、`*.key` 等）。
- **只读代码预览与一键引用**：内置行号与轻量语法高亮，自动识别二进制文件并安全截断超大文件；支持一键复制、点击 `@` 将文件或目录直接加入输入框引用，并在智能体修改文件后自动刷新预览。

## 全局命令面板、跨会话全文检索与 Markdown 导出

- **`Ctrl/Cmd + K` 全局命令面板**：任意页面快速唤起，支持键盘导航新建对话、切换明/暗主题、展开/收起侧栏与文件栏、直达流水线/群聊/记忆/自动化/设置，或按工作区新建任务。
- **跨会话全文检索**：新增 `GET /api/sessions/search`，在命令面板和侧栏搜索框中均可跨历史会话检索标题、提问与回复正文，并展示匹配摘要片段。
- **一键导出 Markdown**：顶栏与命令面板均支持将当前会话的完整提问与回复导出为结构化 `.md` 文件。

## 首屏性能与拆包优化

- 将设置、自动化、长期记忆、群聊、流水线、命令面板与工作区文件栏拆分为按需异步加载分包，前端首屏主包体积降低超过 **52%**（547 KB → 261 KB）。
