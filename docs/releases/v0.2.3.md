## 新增外部智能体（ACP v1）

在 **设置 → 扩展 → 外部智能体** 中可接入本地可信的 ACP v1 stdio 适配器，内置 **Codex**（`codex-acp`）与 **Claude Code**（`claude-agent-acp`）预设，也支持自定义 ACP 程序：

- **对话内直接委派**：选择工作区后，在消息开头输入 `/claude`、`/codex` 或自定义 `/<别名>` 即可将本轮任务交给外部智能体执行，下一条普通消息继续由主模型处理；适配器支持 `session/resume` 或 `session/load` 时自动续接外部上下文。
- **权限模式与交互卡片**：内置预设默认只读/计划模式（Codex 为 `read-only`，Claude Code 为 `plan`），勾选写入后可请求工作区修改；运行中产生的权限确认与表单追问会在时间线内交互并同步提醒到任务中心。
- **连接测试与安全边界**：配置页支持先做 ACP v1 握手测试再启用；Java Harness 不转交自身模型 API Key，不转发历史对话、记忆、附件或 MCP 配置。

详细配置与常见问题见 [外部智能体（ACP）](https://github.com/song782360037/java-harness/blob/master/docs/external-agents.md)。

## 稳定性与体验改进

- **流水线轮询节能**：浏览器标签页或桌面窗口隐藏时自动暂停流水线状态轮询，切回后立即恢复刷新。
- **桌面更新门禁完善**：应用内自动更新准备阶段同步检查流转中的流水线事项，避免在节点切换窗口期中断流转。
- **文档与展示更新**：完善 README 结构，新增演示视频、界面预览图、矢量架构图与外部智能体使用文档。
