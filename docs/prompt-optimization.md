# 提示词优化

普通聊天输入框右侧的 **优化提示词** 按钮会使用当前选择的模型和思考强度，改写尚未发送的草稿。点击后输入框暂时禁止编辑和发送，并在输入区域显示加载动画；完成后自动将结果填回输入框、恢复编辑并聚焦，仍需自行发送。欢迎页没有会话时也能优化，不显示弹窗。

草稿以 `/插件名:命令名` 开头时，只优化命令后的任务描述，原命令标记由代码保留。模型额外生成的命令前缀会被剥离；只有命令标记时需先补充任务描述。

## 上下文与记忆

- 完整保留当前草稿，读取已选择的文件引用、目录和文本附件，沿用原有工作区边界与凭据脱敏。图片只提供文件名，本次优化不识别图片内容。
- 最多加入当前会话、当前工作区最近 6 轮有效的完整问答，优先保留最近的轮次；失败、进行中、模拟任务和子任务不参与。
- 记忆开启时，使用草稿和最近一轮问题的关键词检索当前工作区与全局的生效记忆，沿用关键词匹配、一跳关系扩展、最多 8 条及 2048 Token 的召回上限。未绑定工作区时只检索全局记忆。关闭记忆后仍可结合会话上下文优化。
- 所有输入均按所选模型的上下文窗口计算，预留输出及安全余量。记忆与历史在剩余预算内加入；草稿及附件本身放不下时明确报错，保留原草稿。

历史和记忆是参考资料，当前草稿要求优先；优化指引要求保留原有意图、语言和约束，缺失信息作为待确认事项，不将历史结论当作本次已验证事实。生成质量仍取决于所选模型，发送前可在输入框检查和修改文本。

## 状态与调用

优化会额外调用所选模型，不挂载工具，不创建聊天任务、不绑定附件，也不生成长期记忆或写入正式任务的记忆引用快照。等待上限为模型任务超时与 45 秒中的较小值。模型超时、空结果或异常返回时可重试。

优化失败时保留原草稿、恢复编辑，并在输入框内提示错误，可再次点击优化按钮重试。更换模型、切换会话或工作区等上下文变化会终止页面等待，使旧结果失效，不会覆盖新草稿；已经发往模型的请求仍可能运行到服务端超时。

`POST /api/composer/optimize` 接受 `sessionId`（可省略）、`prompt`、`modelProfileId`、`reasoningEffort`、`mentions` 和 `attachmentIds`。返回 `prompt`、`historyTurns`、`memories`（记忆 ID 与标题）。接口只允许普通会话；群聊、自动化配置页和系统提示词编辑不在本功能范围内。

## 验证

`PromptOptimizationServiceTest` 使用隔离 H2 和本地模型桩，覆盖上下文、记忆开关与工作区隔离、附件权限、预算、模型异常、超时资源释放及工作区变化。`ComposerApiIntegrationTest` 覆盖 HTTP 接口、欢迎页和会话历史无副作用。
