# 长期记忆

侧栏的 **记忆** 打开独立工作台，不中断当前会话。选择工作区或全局记忆后，可搜索正文、筛选状态，并在图谱和列表之间切换。

## 开启与自动生成

- 在 **设置 → 记忆** 选择已配置的生成模型，勾选 **启用自动记忆** 并保存。开关默认关闭，保存在后端，重启和其他浏览器页面共享。
- 开启后自动分批分析已有历史成功对话，并持续处理后续完成的主对话。新完成的对话优先处理。失败、取消和模拟任务、子智能体任务不会单独提取记忆。新任务在提交时捕获工作区身份；旧历史没有身份记录时，只处理目录匹配且归属无歧义的来源，其余跳过。
- 每段对话最多生成 4 条记忆，直接生效，不需要点击“记住”、手动新建或逐条确认。只读取该轮用户输入和最终回答，各自最多 4000、8000 字符；生成会额外调用所选模型，不挂载工具，最长等待 45 秒。
- 设置页和图谱页显示数据库中的真实处理进度。队列持久化，服务重启后继续未完成来源；失败最多自动尝试三次，之后可在设置中重试失败记录。一次完整结果和处理完成标记在同一事务中保存。
- 相同范围内正文相同的内容去重。已经处理完成的来源不再分析；删除或纠正过的正文保留指纹排除记录，避免其他来源再次写入相同原文。该机制不提供语义改写去重。
- 关闭开关会取消当前生成、暂停队列并停止后续召回，已有记忆和历史引用快照保留。再次开启后继续处理。已准备好的任务输入不会被重写。

## 查看和纠正

- 类型包括项目事实、决策、偏好和解决方案。首个标签用于图谱聚类，无标签时按类型聚类。
- 图谱可拖动画布和节点、滚轮缩放，支持复位。选择节点后高亮显式关系和相同标签的节点；实线表示显式关系，虚线表示相同标签，不意味着经过验证的因果关系。
- 在详情中可查看来源摘录、打开原始会话、编辑、归档、删除和添加或删除显式关系。**用新结论替代** 会在同一事务中保存新记忆、归档旧记忆并建立有方向的替代关系。
- 编辑、删除和替代均检查版本号；其他页面已修改的记录会提示刷新。已有记忆的范围不可直接移动。
- 每页最多加载 200 条；需要时点击 **加载更多**。搜索和召回都查询数据库，不局限于已经加载的图谱节点。

## 召回

自动记忆开启时，任务开始会检索当前工作区及全局的生效记忆。未绑定工作区的任务只检索全局记忆。其他工作区和归档记忆不会进入召回。

首版使用英文词和中文相邻双字匹配标题、标签及正文；标题和标签权重更高，再按更新时间排序。关键词命中后，再扩展一跳显式关联的生效记忆，仍限制在当前工作区和全局范围内，关键词命中优先。属于关键词与关系检索，不提供向量语义匹配，也不会自动注入所有偏好。

最多注入 8 条、2048 个估算 Token，并根据本次剩余上下文进一步缩小预算。记忆以 `<retrieved_memory>` 块置于本轮用户消息的问题之前，不进入系统指引，使系统指引保持稳定，便于复用提示词缓存；它占用历史对话的预算。模型输入明确标注记忆属于可能过时的参考资料，不能扩展工具权限或充当执行授权。

记忆不会写进成功对话正文，因此后续轮次不会因为历史组装而重复累积记忆块。每次任务在首次模型输入持久化后，记录当时纳入上下文的记忆标题、正文和版本；回答下的 **本次引用的记忆** 展示这份快照。

修改、归档或删除记忆影响之后的召回，不会重写已经准备好的任务输入、历史对话和历史快照。删除来源会话后，记忆保留提取时的来源摘录，但不能再打开原始会话。删除引用该记忆的任务时，其引用快照一并删除。

## 存储和配置

复用本地 H2，`V21__long_term_memory.sql` 保存记忆、关系及引用快照；`V22__automatic_memory.sql` 增加任务原始工作区身份、持久化设置、处理队列和删除排除指纹。旧版所有已有记忆来源均标记已经处理，避免覆盖人工确认、纠正或归档的结论；有来源的旧自动候选转为生效状态。开关关闭期间仍不会召回。首次使用包含该功能的版本启动时执行迁移。

开关统一由设置页控制，旧版 `HARNESS_MEMORY_EXTRACTION_ENABLED` 不再控制该功能。记忆正文、来源摘录与引用快照属于现有本地数据库的可信存储边界；提取提示会要求模型排除凭据，仍可随时纠正或删除生成的内容。对话分析发送到设置中选择的现有模型连接，不上传到独立记忆服务。

## 验证

`MemorySystemTest` 覆盖开关持久化、历史自动回填、生成直接生效、关闭期间拒绝晚到结果、重启恢复、失败重试、人工纠正与删除排除，以及项目隔离、预算、图谱关联和输入快照。`MemoryApiIntegrationTest` 覆盖设置、版本冲突、进度、管理接口和无效输入。前端 `memory.test.mjs` 覆盖图谱布局稳定性及空数据。

自动记忆默认关闭，与记忆无关的集成测试不会额外调用模型；记忆测试独立开启，并使用本地模拟模型。
